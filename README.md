# 💻 Baku Electronics Automation Bot (Java + Selenium)

This is a Java-based Selenium bot that automates browsing through [Baku Electronics](https://www.bakuelectronics.az), selects products, and adds them to the shopping basket. Developed in IntelliJ IDEA, it's designed for testing, demo purposes, and learning web automation techniques.

---

## 🧰 Tech Stack

- **Language**: Java 17
- **IDE**: IntelliJ IDEA
- **Framework**: Selenium WebDriver
- **Build Tool**: Maven
- **Browser**: Chrome + ChromeDriver

---

## 🔍 Features

- Navigates to [bakuelectronics.az](https://www.bakuelectronics.az)
- Selects products from specific categories
- Clicks and adds products to the basket
- Uses waits, scrolls, and realistic user simulation
- Easily extendable for login, filters, and checkout

---

## 🚀 Getting Started

### Prerequisites

- Java JDK 17 (or compatible)
- Maven
- Google Chrome browser
- ChromeDriver (same version as your browser)
